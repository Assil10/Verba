# Verba 🇩🇪

Verba is an interactive German-learning platform focused on learning through real sentences, context, active recall, and repetition.

The idea came from studying German and realizing that simply memorizing vocabulary is not enough. Seeing how words are actually used in sentences makes it easier to understand grammar, word order, and meaning.

## ✨ Features

- 🇩🇪 Real German sentences for practical learning
- 🧠 Think before revealing the answer
- 🔍 Word-by-word explanations
- 📚 Sentence structure and grammar explanations
- 🔊 Pronunciation support
- 🤖 AI-powered explanations and learning assistance
- 🔄 German → English and English → German modes
- 🧠 Spaced repetition for reviewing sentences and vocabulary
- 📈 Progressive learning from simpler to more advanced sentences

## 🧠 Learning Flow

```text
Real German sentence
        ↓
Think about the meaning
        ↓
Reveal the answer
        ↓
Understand every word
        ↓
Understand WHY the sentence is structured that way
        ↓
Listen to the pronunciation
        ↓
Review it later with spaced repetition
